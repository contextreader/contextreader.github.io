# Market Research Skill — Context Reader

## Purpose
When researching a new market segment for Context Reader, always follow this framework.

## Segment Scoring Dimensions (score each 1–10)
1. Market Size — how many addressable users exist
2. Purchasing Power — average income / ability to spend on tools
3. Pain Intensity — how acute is the contextual translation problem daily
4. Competition Gap — how few existing tools serve this exact need
5. WTP Estimate — inferred willingness to pay per month
6. Localization Effort — how much product changes are needed (lower = better)

## For Each Segment Always Find:
- Population size (university enrollment data, visa/immigration statistics)
- Top 3–5 communities where this segment gathers online (Reddit, Discord, Facebook Groups, YouTube channels)
- At least 3 real Reddit/forum posts showing the pain (screenshot or quote)
- Top 3 competing Chrome extensions targeting this segment + their ratings + 3 common complaints in reviews
- Price benchmarks from similar tools they already pay for
- Any existing .edu email discount programs competitors offer

## Output Format
Always save to /market-research/[segment-name].md with:
- Segment summary (2 paragraphs)
- Scoring table (all 6 dimensions)
- Community list (name, URL, member count)
- Pain evidence (3 quotes/posts)
- Competitor table (tool, rating, key weakness)
- WTP recommendation with rationale

## Quality Standards
- Use real data, not estimates, wherever possible
- Cite sources with URLs
- If data is unavailable, say so explicitly — do not fabricate
- Flag any market trend that has changed in the last 12 months
